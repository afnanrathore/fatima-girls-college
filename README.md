# Fatima Girls College

MERN stack college admissions site (same features and UI as the original Laravel app).

## Folders

- `frontend` — React (Vite)
- `backend` — Express + MongoDB

## Requirements

- Node.js 20+
- MongoDB running locally (`mongodb://127.0.0.1:27017/fatima_girls_college`)

## Setup

```bash
cd fatima-girls-college
npm install
npm run install:all
npm run seed
npm run dev
```

Then open:

- Frontend: http://localhost:5173
- API: http://localhost:5000/api/health

## Admin signin

Open http://localhost:5173/signin

```text
Email: admin@fatimagirlscollege.edu.pk
Password: password
```
